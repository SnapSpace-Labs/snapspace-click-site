# SnapSpace.click — First Full Site Audit

Date: 2026-09-17
Production baseline audited: `SnapSpace-Labs/snapspace-click-site@bc2b7eed21968b87e1a67af932735b7c2dabd823`
Audit branch: `audit/full-site-20260917`

This audit changes no production content. It combines live-site checks from GitHub-hosted Chrome/HTTP runners with repository evidence review.

## Executive result

The live site is structurally healthy and the public claims reviewed are conservative rather than inflated. The main defects are:

1. a real mobile homepage hero overflow/clipping defect;
2. two glossary-token overflow defects on `/resources/`;
3. twelve public HTML pages are unreachable from the homepage through normal internal navigation, including the four secondary hubs `Academia`, `Applications`, `Capabilities`, and `Resources`;
4. the public scientific surface is materially behind qualified work completed after the publication evidence cutoff of 2026-09-12.

The primary scientific risk is omission/under-representation, not overclaiming.

## 1. Mechanical / live-site audit

### PASS

- 13 principal live routes fetched successfully.
- 21 internal HTML routes discovered and returned HTTP 200.
- Primary pages checked have a title, one H1, meta description, canonical URL, `lang=en`, and viewport metadata.
- Expected homepage control-language and proof figures are present.
- Old homepage heading `Distributed compute` is absent.
- New homepage wording `Data centers and compute hardware` is present.
- GitHub-hosted Chrome rendered mobile, tablet, and desktop screenshots.

### Formatting defects

#### FMT-001 — mobile homepage hero clips at 390 px

At 390×844 the homepage H1 overflows its container. DOM measurements:

- H1 client width: 362 px
- H1 scroll width: 410 px

The page globally clips horizontal overflow, so the user sees truncated heading content instead of a scrollbar. Other audited routes did not show the same mobile overflow.

Priority: HIGH.

#### FMT-002 — `/resources/` glossary labels overflow their fixed label width

At tablet and desktop widths:

- `ACKNOWLEDGEMENT`: 150 px client width vs 191 px scroll width
- `UNKNOWN_EFFECT`: 150 px client width vs 171 px scroll width

This does not create whole-page horizontal scrolling, but the token labels spill their intended column.

Priority: MEDIUM.

## 4. Editorial / blind-reader assessment

### Strong

The primary path has a distinct, coherent voice and explains one central idea consistently:

`policy -> enforceable runtime control -> bounded authority -> execution -> effect truth -> evidence`

The separation of `ALLOW / DENY / ESCALATE` from `STOP`, and the preservation/reconciliation of unknown effects, are clear. Claim ceilings are repeatedly explicit. The primary pages do not read like a catalogue of unrelated projects.

### Weak

The scientific depth exists behind the primary path, but much of it is hidden. A new visitor can understand the thesis without understanding the full breadth of qualified work. Because the four secondary hubs have zero inbound links, the site currently suppresses its own supporting material.

Priority: HIGH, but fix with pathways rather than bloating the top navigation.

## 5. Scientific / evidence audit

### Existing public baseline is disciplined

The public flagship claim ledger is intentionally frozen at evidence cutoff `2026-09-12`. It correctly preserves qualification ceilings for bounded authority, effect truth, STOP, federation, institutional handoff, the 409,600/15 DC-SIL point, real two-GPU work, autonomy simulation, and the non-qualified legacy REST durability claim.

The Academia page explicitly states that later evidence must enter a successor cutoff rather than being silently folded into publication v1.0. That rule should be retained.

### Material qualified work not yet adequately represented publicly

#### SCI-001 — SnapSpace Orbit / space-control SIL

Qualified result: `SPACE_SIL_QUALIFIED_BOUNDED_SOFTWARE_SIL_ONLY`.

Evidence includes two deterministic integrated cross-lane runs, repeatability/identity checks, a positive uplink -> continuity -> admission -> release-time authority -> bounded effect -> downlink seam, and 11/11 negative cases including replay, stale state, revoked authority, link loss/reconnect, uncertain effect with zero blind retries, and STOP.

Required public treatment: add a bounded `Space & communications` domain/evidence entry. Do not imply RF, satellite hardware, flight, HIL, production, operational, or regulatory qualification.

Priority: HIGH.

#### SCI-002 — Local Alpha / Thread Bridge live operator control

Qualified 2026-09-16 evidence includes:

- live browser qualification;
- physical `ALLOW_ONCE / DENY / STOP` controls for the fixed bounded `test_smoke` capability;
- browser 16/16 and native/local-alpha 12/12 qualification;
- one-use approval, deny, durable pre-execution STOP, restart recovery and replay recovery;
- same-bound ChatGPT result delivery;
- a separate exact 28-tool read-only convergence round trip: bound ChatGPT tab -> Thread Bridge -> Native Messaging -> Local Alpha MCP -> same bound tab.

Important ceiling: the convergence result explicitly keeps process execution, filesystem mutation and git mutation false, and the browser holds no operator approval secret.

Required public treatment: represent this under Developers / Proof / Evidence as a bounded live operator-control result, not as arbitrary desktop authority or production deployment.

Priority: HIGH.

#### SCI-003 — DC-SIL 007C final requalification and later optimisation ladder

The 2026-09-14 final source-bound requalification is terminally qualified and Terra-approved. It passed 26/26 repair gates, 6/6 semantic-equivalence records and fail-closed adversarial provenance mutations. Fresh process-CPU characterization recorded reductions from 2.23% to 90.23% across the frozen six-cell matrix.

Rank 11, dated 2026-09-15, is semantically qualified for merge with 14 focused/adversarial tests, 49 broad regressions, full 007A qualification, 11/11 frozen matrix, 400/400 dynamic ticks/replay, 7/7 partial-observability checks, and supported resource-cost points at 32/320/3,200 represented servers. Direct energy remains unavailable and no energy claim is permitted.

Required public treatment: update the current compute/data-centre evidence to reflect the later qualification while preserving the exact SIL/process-CPU ceiling. Do not claim physical data-centre performance, direct energy saving, production SLA, or universal acceleration.

Priority: HIGH.

#### SCI-004 — three-attempt escalation governor

SOV-059 freezes the invariant:

`Three unresolved attempts on the same deterministic operation -> ESCALATE; never blind retry four.`

Qualification includes 13/13 base/adversarial PASS, exact C4 replay PASS and 5/5 labelled portability. Restart preserves count; duplicate attempt IDs fail; the handoff carries all three attempts with `DIFFERENT_ROUTE_REQUIRED`; it does not choose or authorise the next route.

Required public treatment: add to human-control/escalation and recovery/evidence surfaces. Preserve the distinction from DENY, STOP and UNKNOWN_EFFECT.

Priority: HIGH.

#### SCI-005 — ZipSnap C4 real-repository qualification

SOV-065 is `QUALIFIED_BOUNDED / CANONICAL` for the frozen campaign. Evidence includes:

- 71/78 live executed arms correct;
- RAW 23/24, CAPSULE 48/54;

- one complete RAW/CAPSULE real patch pair PASS at 229,712 vs 12,772 input tokens (94.44% reduction);

- same-task DeepSeek V4 Pro / GPT-5.6 Luna portability 4/4 correct.

Required public treatment: Research/Evidence rather than a universal homepage compression claim. Preserve the exact frozen-repository/task/model ceiling.

Priority: MEDIUM-HIGH.

#### SCI-006 — ZipSnap C5 autonomous generalisation/deployment preparation

SOV-066 is `AUTONOMOUS_GENERALISATION_PREP_QUALIFIED_LOCAL / EXTERNAL_GATES`. G0-N0 all pass locally, including 41 local repositories, 30-repository diversity set, 12 task types / 36 checks, 32 revisions / 127 checks, provider ABI 10/10, local lifecycle 9/9, shadow policy 7/7 and blind local challenge 60/60.

It explicitly does not upgrade C4. Remaining gates require live provider/model breadth, genuinely unseen external repositories, external deployment/traffic and independent challenge.

Required public treatment: Research/Open Gates, not product-generalisation marketing.

Priority: MEDIUM.

## 6. Scientific verdict

No material public overclaim was identified in the reviewed core claims. Existing language is conservative and usually carries the correct evidence ceiling.

The material issue is that the public scientific record stops too early. The flagship v1.0 publication should remain frozen at 2026-09-12, but the live Evidence / Proof / Domains / Research surfaces need a successor evidence cutoff so qualified work from 14–16 September is visible without rewriting history.
