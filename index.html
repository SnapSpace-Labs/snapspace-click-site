CONSEQUENCE CONTROL FOR AI & AUTOMATION

Decisions can become irreversible consequences. SnapSpace controls the boundary.

SnapSpace decides ALLOW / DENY / ESCALATE, issues bounded authority, controls execution, can STOP active work, and preserves truthful evidence about what actually happened.

See the platformInspect the evidence
CORE MODEL

Proposal is not permission.

PROPOSE→DECIDE→ALLOW / DENY / ESCALATE
ALLOW→GRANT→EXECUTE→OUTCOME→RECEIPT

Only ALLOW can create a bounded grant. A grant is permission to attempt the exact action under current conditions; it is not proof that execution or effect happened.

SEPARATE INTERRUPT

STOP is not a fourth normal decision.

ACTIVE EXECUTION→STOP→CONTAIN→SAFE STATE→RECONCILE→STOP RECEIPT

STOP can prevent further effects where technically possible. It cannot rewrite an irreversible effect as undone, and safe state remains domain-specific.

FEDERATION RULE

SHARE STATE, NOT AUTHORITY.

Independent domains can exchange bounded, purpose/freshness/provenance-bound state. The receiving domain keeps its own admission and consequential authority.
