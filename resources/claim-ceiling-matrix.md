# Public-Safe Claim-Ceiling Matrix

| Area | Supported | Not supported |
|---|---|---|
| Authority | bounded authority/release semantics in tested contracts | universal policy correctness or agent safety |
| Receipts | layered outcome/effect/reconciliation semantics | universal external truth oracle |
| Replay | rejection/same-attempt discipline in tested paths | arbitrary external exactly-once effects |
| STOP | bounded software/SIL interruption and truthful reconciliation | rollback or universal physical safe state |
| Federation | bounded state sharing without authority merger | arbitrary universal federation |
| Represented scale | exact semantic result at 409,600 represented servers / 15 kernels | physical capacity, maximum scale or SLA |
| Real GPU | real two-GPU execution on one host | site/rack/power/cooling independence |
| Institutional handoff | synthetic handoff truth separation | live NHS/clinical/regulatory acceptance |
| Autonomy | closed-loop physical-simulator result | real vehicle or field safety |
| Legacy REST | current adapter behaviour only | restart-durable/durable exactly-once guarantee |

`SEALED` and `CANONICAL` strengthen artifact identity/provenance; they never widen the demonstrated environment.
