MASTER GLOSSARY — CORE TERMS

PROPOSERequest consequential action; creates no authority.

DECIDEEvaluate proposal against current authority, state, policy and evidence.

ALLOWNormal decision permitting the governed path to continue.

DENYNormal decision refusing the proposed consequence; no grant follows.

ESCALATECurrent authority cannot safely decide; further authority, evidence or human resolution is required.

GRANTBounded pre-commit authority for the exact action; not proof of execution.

ATTEMPT IDENTITYDurable identity for the consequential attempt used for duplicate control and reconciliation.

ACKNOWLEDGEMENTEvidence that transport/application responded; not proof of external effect.

UNKNOWN_EFFECTEffect truth is unresolved and non-final; do not guess or blindly retry.

RECONCILIATIONResolve partial, uncertain or conflicting effect truth using the original attempt.

RESPONSIBILITY TRANSFERSeparate truth that responsibility has actually moved to the receiver.

STOPAuthenticated interrupt for active consequential execution; not a fourth normal decision and not rollback.

SAFE STATEDomain-specific containment target; there is no universal safe state.

BOUNDED PROJECTIONPurpose/freshness/provenance-bound state shared without transferring authority.

SOVEREIGN DOMAINBoundary retaining its own canonical state, admission, decision and consequential authority.

CLAIM CEILINGStrongest statement the cited evidence can support without overclaiming.

SEALED / CANONICALProvenance modifiers; they strengthen identity and custody, not claim scope.

TRUTH LADDER

Know exactly what is proved at each stage.

Decision → grant/authority → attempt → execution → transport acknowledgement → application acknowledgement → effect → receiver admission → responsibility transfer → reconciliation/finality.

Acknowledgement is not effect. Completion is not responsibility transfer.

STANDARDS BOUNDARY

External standards and frameworks are references only unless an exact tested binding or mapped assessment exists. Reference is not certification or compliance.

CLAIM CEILING

The public reference layer explains and traces qualified architecture and evidence. It does not widen qualification, create universal receipt/federation/safe-state claims, or repair an implementation gap by documentation alone.
