# Public Open Reality Gates

These gates define what additional evidence is required before broader public claims are defensible.

| Gate | Current evidence ceiling | Evidence required to broaden |
|---|---|---|
| Physical data-centre independence | represented SIL + one-host GPU | independent hosts/racks/sites with representative power/network/failure domains |
| Production capacity/SLA | exact tested stress point | production-like load, availability/error budgets and repeated capacity methodology |
| Institutional/clinical handoff | synthetic software | representative institutional pilot plus clinical/regulatory acceptance where applicable |
| Issuer/institution acceptance | offline public-rule fixture | actual issuer/receiver/regulator or representative pilot evidence |
| Human legitimacy/comprehension | deterministic fixture | representative human study and device/identity assurance |
| Agent deployed-host state | bounded local sealed software | privileged host promotion + installed-identity verification + representative host qualification |
| Physical autonomy | physical simulator | HIL, target hardware, field/radio/C2 and regulatory evidence |
| Defence-adjacent physical performance | software/SIL STOP | representative sensors/platform/environment and separately authorised physical-effect testing |
| Physical STOP/safe state | software/SIL semantics | domain-specific physical safe-state qualification and measured propagation latency |
| Network compression | semantic representation reduction only | wire-level protocol/network measurement on specified transports |
| Arbitrary/degraded federation | bounded pinned composition | larger membership, degraded links, partition/rejoin and physical separation |
| Scaling law | tested rungs / one 409,600 point | pre-registered multi-point scaling study with repeated measurements |
| Legacy REST durability | volatile active persistence class | durable implementation or narrowed contract + fresh crash/restart/race qualification |
